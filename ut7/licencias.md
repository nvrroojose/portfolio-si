# Licencias de Software

En esta sección se documentan los principales tipos de licencias de software y el procedimiento para verificar la licencia de paquetes instalados en sistemas Linux.

## Comparativa de licencias

| Licencia | Tipo | Código abierto | Uso comercial | Copyleft (obligación de mantener licencia) |
| :--- | :--- | :--- | :--- | :--- |
| **GPL v3** | Libre / Copyleft fuerte | Sí | Sí | Sí, estricta en obras derivadas |
| **MIT** | Libre / Permisiva | Sí | Sí | No, permite cerrar el código derivado |
| **Apache 2.0** | Libre / Permisiva | Sí | Sí | No, incluye concesión expresa de patentes |
| **Propietaria (EULA)** | Privativa | No | Según contrato | No aplicable (código cerrado) |
